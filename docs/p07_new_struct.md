4.  Виводить на екран повний склад групи.

## Частина 1: Креслення (`struct`) та Проблема

Спочатку, давайте опишемо нашого гравця. Ми використаємо `struct` з файлів `TestStructPerson.cpp` та `TestStructV1.cpp` як основу.

```cpp
#include <iostream>
#include <string>
#include <iomanip> // Для красивого виводу

// Креслення для одного гравця
struct Player {
    std::string name;
    std::string className;
    int level;
};
```

**Проблема:**
Якби ми хотіли створити групу з 3-х гравців, ми б написали:
`Player party[3];`
Але що, як кількість гравців `partySize` вводить користувач?
`int partySize;`
`std::cin >> partySize;`
`Player party[partySize]; // ПОМИЛКА КОМПІЛЯЦІЇ!`

Статичні масиви вимагають, щоб їхній розмір був відомий *під час компіляції*. Нам потрібен динамічний масив.

## Частина 2: `new[]` для структур

**Рішення:** Ми використаємо оператор `new[]`, щоб виділити пам'ять у "купі" (heap) *під час виконання* програми.

```cpp
int partySize;
std::cout << "Скільки гравців у вашій групі? ";
std::cin >> partySize;

// 1. Динамічно виділяємо масив з 'partySize' структур Player
Player* party = new Player[partySize];

// ЩО МИ ОТРИМАЛИ?
// 'party' - це ВКАЗІВНИК на ПЕРШИЙ елемент (Player)
// у щойно створеному масиві.
```

## Частина 3: Доступ до елементів (`.` чи `->`?)

Тепер у нас є вказівник `party`. Як нам отримати доступ до `name` другого гравця? Тут ми комбінуємо знання з `CStructPointer.cpp`.

Існує два синтаксиси:

### Спосіб 1: Синтаксис масивів (Рекомендований)

Найпростіший спосіб — поводитися з вказівником `party` так, ніби це звичайний масив.

  * `party[0]` — це *об'єкт* Player (перший гравець).
  * `party[1]` — це *об'єкт* Player (другий гравець).

Оскільки це **об'єкти**, ми використовуємо **оператор-крапку (`.`)**.

```cpp
// Зчитуємо дані для першого гравця
std::cout << "Ім'я гравця 1: ";
std::cin >> party[0].name;
std::cout << "Клас гравця 1: ";
std::cin >> party[0].className;
party[0].level = 1;
```

### Спосіб 2: Синтаксис вказівників (Pointer Arithmetic)

Ми пам'ятаємо, що `party` — це вказівник.

  * `party` вказує на гравця 0.
  * `(party + 1)` — це вказівник на гравця 1.
  * `(party + 2)` — це вказівник на гравця 2.

Оскільки `(party + 1)` — це **вказівник**, ми використовуємо **оператор-стрілку (`->`)**.

```cpp
// Доступ до імені другого гравця (індекс 1)
std::cout << "Ім'я гравця 2: ";
std::cin >> (party + 1)->name;
```

**Висновок:** `party[i].name` — це просто зручний синтаксис для `(party + i)->name`. Вони роблять *абсолютно те саме*.

## Частина 4: Збираємо все разом (Цикли та `delete[]`)

Давайте напишемо повну програму "Менеджер Паті".

<details markdown="1">
<summary>Натисніть, щоб побачити повний код</summary>

```cpp
#include <iostream>
#include <string>
#include <iomanip> // Для красивого виводу
#include <limits>  // Для cin.ignore()

// Креслення для одного гравця
struct Player {
    std::string name;
    std::string className;
    int level;
};

int main() {
    int partySize;
    std::cout << "Скільки гравців у вашій групі? ";
    std::cin >> partySize;

    // --- 1. Виділення пам'яті ---
    Player* party = new Player[partySize];
    std::cout << "Виділено пам'ять для " << partySize << " гравців." << std::endl;

    // Очищуємо буфер cin
    std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');

    // --- 2. Заповнення масиву (використовуємо синтаксис []) ---
    for (int i = 0; i < partySize; ++i) {
        std::cout << "\n--- Гравець " << i + 1 << " ---" << std::endl;
        
        std::cout << "Введіть ім'я: ";
        // getline потрібен, якщо ім'я може мати пробіл
        std::getline(std::cin, party[i].name); 

        std::cout << "Введіть клас (напр. 'Warrior'): ";
        std::getline(std::cin, party[i].className);

        party[i].level = 1; // Всі починають з 1 рівня
    }

    // --- 3. Вивід масиву (використовуємо синтаксис ->) ---
    std::cout << "\n--- СКЛАД ВАШОЇ ГРУПИ ---" << std::endl;
    std::cout << std::left; // Вирівнювання по лівому краю
    std::cout << std::setw(20) << "Ім'я" << " | " << "Клас" << std::endl;
    std::cout << "---------------------------------" << std::endl;

    for (int i = 0; i < partySize; ++i) {
        std::cout << std::setw(20) << (party + i)->name 
                  << " | " 
                  << (party + i)->className 
                  << " (Рівень " << (party + i)->level << ")" 
                  << std::endl;
    }

    // --- 4. Звільнення пам'яті ---
    // Обов'язково використовуємо delete[]
    delete[] party;
    party = nullptr; // Гарна практика

    std::cout << "\nПам'ять звільнено. Групу розформовано." << std::endl;
    
    return 0;
}
```

</details>

## Частина 5: Бонус — C-стиль `typedef`

У файлах `ListNode.cpp` та `StructFract.cpp` ви бачили ключове слово `typedef`. Це старий C-спосіб створення псевдонімів.

```c
// C-стиль (старий)
typedef struct {
  int num;
  int denum;
} fraction;

// Тепер 'fraction' - це псевдонім для 'struct {...}'
fraction pi; 
```

У C++ `typedef` не є обов'язковим для `struct`. Як тільки ви оголосили `struct Player`, ви можете одразу писати `Player p1;`.

У сучасному C++ замість `typedef` частіше використовують `using`:

```cpp
// Сучасний C++ псевдонім
using PlayerList = Player*; 
```

## 🧠 Контрольні питання

1.  **Проблема.** Чому ми не могли використати `Player party[partySize];`?
2.  **Синтаксис `new`**. Напишіть *один* рядок коду, який динамічно створює масив з 25 структур `Player` і повертає вказівник на нього.
3.  **Синтаксис `delete`**. Напишіть *один* рядок коду для звільнення пам'яті, виділеної у питанні 2.
4.  **Доступ.** У вас є `Player* partyList = new Player[10];`. Як звернутися до поля `name` **третього** гравця (індекс 2), використовуючи синтаксис **масиву** (`[]`)?
5.  **Доступ.** Як зробити те саме, що й у питанні 4, але використовуючи синтаксис **вказівника** (`->` та арифметику)?

<details markdown="1">
<summary>Натисніть, щоб побачити відповіді</summary>

**1. Проблема:**
Розмір статичного масиву (`Player party[...]`) має бути **константою, відомою під час компіляції**. `partySize` — це *змінна*, значення якої стає відомим лише *під час виконання* програми (runtime).

**2. Синтаксис `new`:**

```cpp
Player* myList = new Player[25];
```

**3. Синтаксис `delete`:**

```cpp
delete[] myList;
```

*(Дужки `[]` є критично важливими для масивів\!)*

**4. Доступ (синтаксис масиву):**

```cpp
partyList[2].name = "Taras";
```

*(Це просто, бо `partyList[2]` — це об'єкт `Player`, тому ми використовуємо `.name`)*

**5. Доступ (синтаксис вказівника):**

```cpp
(partyList + 2)->name = "Taras";
```

*(Тут `(partyList + 2)` — це вказівник на третій елемент, тому ми використовуємо `->name`)*

</details>
