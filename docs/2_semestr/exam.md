## Лекція 13: Філософія ООП

1. Наведіть приклад конструктора, який **не** встановлює інваріант класу. Які наслідки для об'єктів після створення?
2. Якщо в конструкторі виконується `new MyClass()`, що **обов'язково** має бути в деструкторі і чому?
3. Чи може деструктор мати параметри? Обґрунтуйте відповідь з точки зору виклику з боку компілятора.
4. Для класу `Gun` з полем `ammo` сформулюйте інваріант і поясніть, які поля мають бути `private`.
