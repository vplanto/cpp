# Основи програмування
## C++ Engineering: Архітектура пам'яті та системне мислення

> **Дисклеймер / Disclaimer**  
> Авторська декларація: Базовий контент, концепцію та архітектуру цього курсу розроблено автором на основі власних лекцій та презентацій. Інструменти штучного інтелекту (LLM) використано виключно як технічний засіб для конвертації форматів (Slides → Markdown) та розгортання текстових тез. Увесь підсумковий текст, архітектурні схеми та код повністю вичитано, верифіковано та затверджено автором.

Цей курс є частиною дисципліни "Основи програмування", яка читається студентам 1-го курсу.

**Навчально-методичний комплекс:** [Силабус](syllabus.md) · [Методичні рекомендації](methodology.md) · [Технічні джерела](sources.md) · [Декларація](DISCLAIMER.md)

**Фокус курсу:** Ми не просто вчимо синтаксис C++, ми вчимося розуміти, як працює комп'ютер. Курс фокусується на управлінні пам'яттю (Stack vs Heap), роботі з вказівниками, розумінні низькорівневих процесів та написанні високоефективного коду. Це фундамент для майбутніх інженерів та математиків.

Структура курсу:

1й семестр

* 1 лекція на тиждень
* 1 практикум 1 раз тиждень
