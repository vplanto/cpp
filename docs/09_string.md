## 1\. Дві "сім'ї" рядків у C++

C++ підтримує два типи рядків, і ми маємо їх чітко розрізняти.

  * **C-String (C-рядок):** "Низькорівневий" тип, успадкований з мови C.

      * Це просто масив `char`, що закінчується `\0`.
      * **Проблеми:** Небезпечний (легко спричинити переповнення), незручний (всі операції, як-от копіювання чи об'єднання, вимагають ручних циклів або спеціальних функцій).

  * **`std::string` (C++ String Class):** "Високорівневий" об'єктний тип, представлений у C++98.

      * Це **клас**, що "обгортає" C-рядок і керує пам'яттю *автоматично*.
      * Він сам стежить за своїм розміром, не допускає переповнень і надає купу зручних методів.

> **Золоте правило:** **Завжди надавайте перевагу `std::string`**. Використовуйте C-рядки (`char[]`) тільки тоді, коли це абсолютно необхідно (наприклад, для деяких старих бібліотек або аргументів командного рядка).

## 2\. Як використовувати `std::string`

### Підключення та оголошення

Щоб використовувати `std::string`, потрібно підключити заголовок `<string>`.

```cpp
#include <iostream>
#include <string> // Підключення бібліотеки для роботи з std::string
using namespace std;

int main() {
    // Різні способи ініціалізації:
    
    // 1. З рядковим літералом
    string str1("Hello"); 
    string str2 = "world"; 

    // 2. Створення порожнього рядка
    string str3; 

    // 3. Копіювання іншого std::string
    string str4(str1); 
    string str5 = str2; // Також копіювання
}
```

### Ввід/Вивід: `cin` проти `getline`

Це найважливіша практична відмінність.

  * `cin >> string` зчитує лише **одне слово** (до першого пробілу).
  * `getline(cin, string)` зчитує **весь рядок** (до натискання `Enter`).

**Приклад (Наш "продукт" — реєстрація користувача):**

```cpp
string nickname;
string fullName;

cout << "Введіть нікнейм (одне слово): ";
cin >> nickname; // Користувач вводить "MatrixMaster"

cout << "Введіть ваше повне ім'я: ";
// 🚨 ПРОБЛЕМА!
cin >> fullName; // Користувач вводить "Taras Shevchenko"
                 // У 'fullName' потрапить ЛИШЕ "Taras".
                 // "Shevchenko" залишиться в буфері і зламає наступний `cin`.
```

**Рішення:**

```cpp
// ... після cin >> nickname; ...

// 1. "З'їдаємо" символ '\n' (Enter), що залишився в буфері після cin
cin.ignore(numeric_limits<streamsize>::max(), '\n'); 

cout << "Введіть ваше повне ім'я: ";
getline(cin, fullName); // Тепер зчитає "Taras Shevchenko"

cout << "Вітаємо, " << nickname << " (" << fullName << ")" << endl;
```

### ❓ Питання до групи

У практикумі `p01` ("MVP матчу") ми змішували `cin.getline()` (для нікнейму) та `cin >>` (для кілів). Чому нам *обов'язково* потрібно було викликати `cin.ignore()` *після* `cin >> kills[i];`?

<details markdown="1">
<summary>Натисніть, щоб побачити відповідь</summary>
Тому що `cin >> kills[i];` зчитує число, але залишає в буфері символ `\n` (Enter), який користувач натиснув. Наступний виклик `cin.getline()` (на початку наступної ітерації циклу) побачив би цей `\n`, вирішив, що користувач ввів порожній рядок, і не дав би ввести нікнейм. `cin.ignore()` очищує цей `\n` з буфера.
</details>

## 3\. "Інструменти" `std::string` (Операції)

`std::string` — це об'єкт. Він має вбудовані "інструменти" (методи), які викликаються через крапку.

### Довжина та перевірка на порожнечу

```cpp
string str = "Привіт";

cout << str.length() << endl; // 12 (символи кирилиці можуть бути > 1 байта, 
                              // але length() повертає кількість байт)
cout << str.size() << endl;   // 12 (size() і length() роблять те саме) 

string emptyStr;
if (emptyStr.empty()) { // .empty() - швидкий спосіб перевірки 
    cout << "Рядок порожній!" << endl;
}
```

Так, **абсолютно точно** 12 це розмір строки "Привіт".

#### 1. `std::string` — це "контейнер байтів"

`std::string` (як і C-string `char[]`) насправді не знає нічого про "символи" в людському розумінні (кирилиця, ієрогліфи, емодзі). Він просто зберігає послідовність елементів типу `char`.

За стандартом C++, один `char` **завжди** дорівнює **1 байту**.

Тому, коли ви викликаєте `str.length()` або `str.size()`, ви отримуєте відповідь на питання: "Скільки `char`-ів (тобто, скільки **байт**) у цьому рядку?"

#### 2. UTF-8 та кирилиця

Ваш редактор коду (і компілятор) найімовірніше зберігає ваш `.cpp` файл в кодуванні **UTF-8**.

* У кодуванні UTF-8 символи англійського алфавіту (A-Z) займають 1 байт.
* Але символи кирилиці (як `П`, `р`, `и`, `в`, `і`, `т`) займають **2 байти кожен**.

#### 3. Що бачить `std::string`?

Коли ви пишете `string str = "Привіт";`, відбувається наступне:
1.  Компілятор перетворює "Привіт" на послідовність байтів UTF-8.
2.  `"Привіт"` -> (6 символів)
3.  `[П][р][и][в][і][т]` -> (6 символів * по 2 байти) -> `[0xD0 0x9F][0xD1 0x80][0xD0 0xB8][0xD0 0xB2][0xD1 0x96][0xD1 0x82]`
4.  `std::string` отримує **12 байт** даних (12 `char`-ів).

Тому:
* `str.length()` повертає **12** (кількість байт / `char`-ів).
* Кількість "людських" символів (гліфів) — **6**.

Це фундаментальна відмінність. Щоб порахувати "справжню" кількість символів (6), програмісти мають використовувати спеціальні бібліотеки для роботи з Unicode, які вміють "читати" UTF-8 послідовності. Для `std::string` ваш рядок — це просто 12 байтів даних.

### Об'єднання (Конкатенація)

Використовуйте `+` або `+=`. Це набагато простіше, ніж `strcat()` для C-рядків.

```cpp
string firstName = "Taras";
string lastName = "Shevchenko";

// Оператор + створює новий рядок 
string fullName = firstName + " " + lastName; // "Taras Shevchenko"

// Оператор += додає до існуючого рядка 
firstName += " Hryhorovych"; // firstName тепер "Taras Hryhorovych"
```

### Доступ до символів: `[ ]` проти `.at()`

  * **Оператор `[]` (швидкий, але небезпечний):**

      * Дає прямий доступ до символу, як у C-масиві.
      * **Не перевіряє** вихід за межі рядка.
      * `str[0] = 'h';` // "h�ривіт"

  * **Метод `.at()` (безпечний, але трохи повільніший):**

      * Робить те саме, але **перевіряє індекс**.
      * Якщо індекс неправильний, програма "впаде" з чіткою помилкою, що набагато краще, ніж пошкодження пам'яті.
      * `str.at(0) = 'h';` // "h�ривіт"

### ❓ Питання до групи

Ми знову бачимо компроміс, як і з вказівниками. Коли б ви використали `[]`, а коли `.at()`?

<details markdown="1">
<summary>Натисніть, щоб побачити відповідь</summary>

  * **Використовуйте `[]`:** У критичних для продуктивності циклах, *коли ви абсолютно впевнені* у своїй логіці (наприклад, `for (int i = 0; i &lt; str.length(); ++i)` — тут `i` ніколи не вийде за межі).
  * **Використовуйте `.at()`:** У всіх інших випадках, особливо коли індекс приходить звідкись "ззовні" (наприклад, від користувача). Краще отримати чітку помилку, ніж годинами шукати, чому у вас пошкодилися дані.
</details>


### Порівняння рядків

Використовуйте логічні оператори `==` та `!=`. Вони порівнюють вміст рядків, враховуючи регістр.

```cpp
string pass1 = "Password123";
string pass2;
cin >> pass2;

if (pass1 == pass2) { // 0, якщо рівні 
    cout << "Доступ дозволено" << endl;
} else {
    cout << "Паролі не збігаються" << endl;
}
// 'Hello' != 'hello'
```

*Існує також метод `.compare()`, але `==` зазвичай простіший і чистіший.* 

### Пошук та вирізання підрядка (Substring)

  * **`.find(str)`**: Шукає підрядок і повертає індекс *першого* входження, або `string::npos`, якщо не знайдено.
  * **`.substr(startIndex, length)`**: Вирізає шматок рядка.

```cpp
string logLine = "ERROR: System failure on sector 7.";

// Пошук
size_t errorPos = logLine.find("ERROR"); // size_t - це тип для індексів

if (errorPos != string::npos) { // npos - константа "не знайдено"
    cout << "Знайдено помилку на позиції: " << errorPos << endl;

    // Вирізання
    string errorMsg = logLine.substr(errorPos + 7, 14); // "System failure" 
    cout << "Повідомлення: " << errorMsg << endl;
}
```

## 4\. Бонус: Робота з `<algorithm>`

Бібліотека `std::string` тісно інтегрована з іншими частинами STL, наприклад, з `<algorithm>`.

```cpp
#include <string>
#include <algorithm> // Підключаємо алгоритми

string msg = "Hello, world!";

// Замінюємо всі 'l' на '_'
replace(msg.begin(), msg.end(), 'l', '_'); // 

cout << msg << endl; // "He__o, wor_d!"
```

## 5\. Бонус: Форматування виводу (`<iomanip>`)

Коли ми виводимо рядки та числа, часто хочеться вирівняти їх у гарні стовпчики. Для цього існує `<iomanip>`.

  * `setw(width)`: Встановлює ширину *наступного* поля (не "липкий").
  * `left` / `right`: Вирівнювання у цьому полі.
  * `setfill(char)`: Чим заповнювати порожнє місце (за замовчуванням — пробіл).
  * `fixed` / `setprecision(n)`: Для `double` — показувати `n` знаків після коми.

**Приклад (Форматування чеку):**

```cpp
#include <iomanip>

cout << left; // Вирівнювання по лівому краю
cout << setfill('.'); // Заповнювач

cout << setw(20) << "Dji Mavic 3T" << " 1 " << setw(10) << 150000.00 << endl;
cout << setw(20) << "Starlink Kit" << " 1 " << setw(10) << 25000.00 << endl;
```

**Результат:**

```
Dji Mavic 3T........ 1 150000.00
Starlink Kit........ 1 25000.00 
```
